# 📑 Профили

<span class="hover-text-test">Крутая штука, чтобы посмотреть, что за игрок перед тобой</span>

Профили - отличный способ похвастаться своей статистикой и репутацией  
В нем можно посмотреть:
- Имя игрока
- Его броню
- Привязанный дискорд
- Наигранные часы
- Лайки/Дизлайки от других игроков
- Клан игрока

Чтобы открыть профиль нажмите **Шифт+ПКМ** по игроку напротив или же командой <span class="inline-badge badge-purple">**/profile <ник_игрока>**</span>

  <img src="/profiles.png" alt="Гифка с сайта" style="width: 700px">

</figure>

По той же команде без указания игрока можно открыть свой профиль

<figure>
  <img src="/profiles1.png" alt="Гифка с сайта" style="width: 700px">
  <figcaption>Личный профиль</figcaption>
</figure>

По середине, вместо репутации, появятся 2 кнопки: Темы и Настройки  
С помощью них можно настроить фоновую тему своего профиля (открываются за какие-либо достижения) или же скрыть отображение уже поставленных лайков и дизлайков

:::warning
Функционал профилей еще будет дополняться
:::
